Web Development

A booking platform for a local tailor shop

Fatima Njoya
Web Development Bootcamp · Cohort 4
Project screenshot / media placeholder

The brief

A local tailor shop was managing appointments entirely over WhatsApp, with no way to see availability at a glance. Fatima built a lightweight booking site so customers could see open slots and book directly.

What she built

A responsive booking calendar, SMS confirmation via a local provider, and a simple admin view for the shop owner to manage slots — built and deployed over four weeks of the bootcamp.

"I didn't expect my final project to actually get used by a real shop the week after I presented it."
— Fatima Njoya

Outcome

The shop owner adopted it the week after the cohort's final presentations — now cited as one of the bootcamp's example outcomes for prospective applicants.
