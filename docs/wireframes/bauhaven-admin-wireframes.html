Only Admin can edit enrollment (create/withdraw); Staff have read-only tracking access per the spec — reflected here by "Edit" only appearing on active rows for this Admin-logged-in view. A Staff view shows neither Edit nor "+ New enrollment", and the write routes refuse a non-Admin reached directly. Closed rows carry no action button: completed and withdrawn are terminal in v1, and there is no enrollment detail screen, so the earlier "View" control was dropped. Every duration carries its qualifier — "(standard)" or "(override: +2mo)" — rather than only the overridden ones. Below the md breakpoint these rows become stacked cards.
Where a new enrollment comes from: not from an approved Application. enrollments.user_id requires a users row, and an applicant has no account until they sign up — so the chain is Application approved → invited → signs up → enrolled. The invitation step isn't built yet. See Bauhaven-Admin-Feature-Spec.md §8.
